# Contributing to LRCLib

Thank you for your interest in contributing to LRCLib! This document provides guidelines for contributing to this project.

## Code of Conduct

This project is maintained by volunteers and serves the music community. We expect all contributors to:
- Be respectful and constructive
- Focus on what's best for the community
- Show empathy towards other contributors

## How to Contribute

### Reporting Issues

1. Check if the issue already exists
2. Provide detailed information about the problem
3. Include steps to reproduce if applicable
4. Be patient - this is a volunteer-run project

### Submitting Changes

1. Fork the repository
2. Create a new branch for your changes
3. Make your changes with clear, descriptive commits
4. Test your changes thoroughly
5. Submit a pull request with a clear description

### Content Submissions

**Important**: Only submit lyrics that you have legal authorization to share.

- Do not submit copyrighted content without permission
- Respect intellectual property rights
- When in doubt, don't submit

## Legal Compliance

All contributors must:
- Respect copyright and intellectual property laws
- Only submit content they have the right to share
- Understand that unauthorized submissions may result in DMCA takedown requests

By contributing, you agree that your contributions will be made available under the same license as the project.

## Questions?

If you have questions about contributing, please open an issue for discussion.
